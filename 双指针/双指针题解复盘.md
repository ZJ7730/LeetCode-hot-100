## H_3 - 无重复字符的最长子串【Hot 100】

### 核心思路

用滑动窗口维护当前无重复子串。窗口范围是 `[left, right]`，`window` 保存窗口中的字符，并始终保证其中没有重复字符。

- `right` 逐个尝试加入新字符，负责扩张窗口。
- 若新字符已经在 `window` 中，说明窗口不合法；不断移动 `left` 并删除左侧字符，直到旧重复字符离开窗口。
- 窗口恢复合法后加入当前字符，再用窗口长度更新答案。

### 面试速记

```text
滑动窗口维护无重复字符：right 扩张，遇到重复就 left 不断收缩；
删除旧重复字符后加入当前字符，窗口合法时更新最大长度。
```

### 当前题解代码

```java
public int lengthOfLongestSubstring(String s) {
    HashSet<Character> window = new HashSet<>();

    int left = 0;
    int res = 0;

    for (int right = 0; right < s.length(); right++) {
        char rightChar = s.charAt(right);

        while (window.contains(rightChar)) {
            window.remove(s.charAt(left));
            left++;
        }

        window.add(rightChar);
        res = Math.max(res, right - left + 1);
    }
    return res;
}
```

### 窗口不变量

```text
window 中始终没有重复字符。
因此窗口合法时：window.size() == right - left + 1。
```

### 关键变量

| 变量 | 含义 |
| --- | --- |
| `left` | 当前窗口的左边界，只在发现重复时右移。 |
| `right` | 当前窗口的右边界，遍历字符串并尝试加入字符。 |
| `window` | 当前窗口中的字符集合，始终不含重复字符。 |
| `res` | 遍历过程中出现过的最大合法窗口长度。 |

### 为什么必须使用 `while`

`while` 的目标不是删除一次，而是持续收缩窗口，直到当前 `rightChar` 的旧副本被删除。

```text
s = "abba"

right 指向第二个 b 前，窗口为 "ab"
加入 b 会重复：
删除 a -> 窗口仍为 "b"，仍含 b，不能停止
删除 b -> 窗口为空，重复消失
加入当前 b -> 窗口为 "b"
```

所以不能写成 `if`；只删除一次可能无法让窗口恢复为无重复状态。

### 示例：`s = "abcabcbb"`

```text
right=0, 加 a: 窗口 "a"，res=1
right=1, 加 b: 窗口 "ab"，res=2
right=2, 加 c: 窗口 "abc"，res=3
right=3, 加 a 重复：删除旧 a，再加当前 a，窗口 "bca"，res=3
right=4, 加 b 重复：删除旧 b，再加当前 b，窗口 "cab"，res=3
...
```

最终最长无重复子串长度是 `3`。

### 复杂度

- 时间复杂度：`O(n)`。`left` 和 `right` 都只会从左向右移动，任意字符最多加入和删除各一次。
- 空间复杂度：`O(min(n, 字符集大小))`，`window` 最多保存一个无重复窗口的字符数。

### 易错点

- `res` 要在窗口恢复合法并加入 `rightChar` 后更新。
- `window.remove(s.charAt(left))` 与 `left++` 必须同步执行，否则集合和窗口边界不一致。
- 题目求的是连续子串，不是子序列，因此必须维护连续区间 `[left, right]`。
