### 按状态模型分类

#### 基础线性递推

```text
70. 爬楼梯
```

#### 选与不选

```text
198. 打家劫舍
416. 分割等和子集
```

每个元素都面临“选择当前”和“不选择当前”两种决策。H_198 求最大值，H_416 判断能否凑出目标值。

#### 完全背包

```text
279. 完全平方数
322. 零钱兑换
139. 单词拆分
```

候选项可以重复使用，通常按照容量从小到大更新。

#### 子序列与连续子数组

```text
300. 最长递增子序列：元素可以跳过。
152. 乘积最大子数组：元素必须连续。
```

#### 字符串 DP

```text
139：前缀能否拆分
32：以当前位置结尾的有效长度
5：区间是否回文
1143：两个前缀的公共子序列长度
72：两个前缀的最少编辑次数
```

字符串 DP 首先要说明 `dp` 下标表示真实字符下标，还是“前 `i` 个字符”。


## 动态规划五步法

```text
1. 明确 dp 数组和下标的含义。
2. 推导状态转移公式。
3. 确定初始状态。
4. 确定遍历顺序。
5. 用小规模示例验证 dp 数组。
```

面试时先说清楚 `dp[i]` 的业务含义，再解释递推公式从哪里来。状态定义清楚后，初始化和遍历顺序通常可以自然推出。

## H_70 - 爬楼梯【Hot 100】

### 核心思路

定义 `dp[i]` 表示爬到第 `i` 阶楼梯的方法数。到达第 `i` 阶的最后一步只有两种情况：

```text
从第 i - 1 阶走 1 阶到达。
从第 i - 2 阶走 2 阶到达。
```

两种情况互不重复，所以方法数相加：

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

### 面试速记

```text
dp[i] 表示到第 i 阶的方法数；最后一步只能从 i-1 走 1 阶，
或从 i-2 走 2 阶，所以 dp[i] = dp[i-1] + dp[i-2]。
初始化 dp[1]=1、dp[2]=2，从前向后递推。
```

### 当前题解代码

```java
public int climbStairs(int n) {
    if (n <= 2) {
        return n;
    }
    int[] dp = new int[n + 1];
    dp[1] = 1;
    dp[2] = 2;

    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i - 2] + dp[i - 1];
    }
    return dp[n];
}
```

### 动态规划五步分析

#### 1. `dp` 数组含义

```text
dp[i] = 爬到第 i 阶楼梯的不同方法数
```

`dp[i]` 记录的是方案数量，不是到达第 `i` 阶所需的最少步数。

#### 2. 状态转移公式

要到达第 `i` 阶，最后一步只能走 `1` 阶或 `2` 阶：

```text
第 i-1 阶 --走 1 阶--> 第 i 阶，共有 dp[i-1] 种前置方案
第 i-2 阶 --走 2 阶--> 第 i 阶，共有 dp[i-2] 种前置方案
```

因此：

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

这种思考方式可以概括为：不直接枚举所有完整方案，而是分析“最后一步从哪里来”。

#### 3. 初始化

```text
dp[1] = 1：只有 1 一种走法。
dp[2] = 2：可以走 1+1，也可以直接走 2。
```

代码提前处理 `n <= 2`：

```java
if (n <= 2) {
    return n;
}
```

这样后面可以安全地初始化 `dp[1]`、`dp[2]`，并直接从 `i=3` 开始计算。

#### 4. 遍历顺序

```java
for (int i = 3; i <= n; i++)
```

因为 `dp[i]` 依赖已经计算出的 `dp[i-1]` 和 `dp[i-2]`，所以必须从小到大、从前向后递推。

#### 5. 举例验证

当 `n=5` 时：

```text
dp[1] = 1
dp[2] = 2
dp[3] = dp[2] + dp[1] = 3
dp[4] = dp[3] + dp[2] = 5
dp[5] = dp[4] + dp[3] = 8
```

最终 DP 数组为：

```text
下标 i： 1  2  3  4  5
dp[i]：  1  2  3  5  8
```

所以爬到第 `5` 阶共有 `8` 种方法。

### 图解状态来源

```text
                    走 1 阶
第 i-1 阶，共 dp[i-1] 种 --------┐
                                  ├──> 第 i 阶
第 i-2 阶，共 dp[i-2] 种 --------┘
                    走 2 阶

dp[i] = dp[i-1] + dp[i-2]
```

### 空间优化

当前题解使用 `dp` 数组，空间复杂度是 `O(n)`。因为计算当前状态只需要前两个状态，可以使用滚动变量优化为 `O(1)`：

```java
public int climbStairs(int n) {
    if (n <= 2) {
        return n;
    }

    int previousTwo = 1;
    int previousOne = 2;

    for (int i = 3; i <= n; i++) {
        int current = previousTwo + previousOne;
        previousTwo = previousOne;
        previousOne = current;
    }

    return previousOne;
}
```

面试中可以先写更直观的 DP 数组版本，再说明只依赖前两个状态，能够使用滚动变量优化空间。

### 复杂度

- 当前题解时间复杂度：`O(n)`。
- 当前题解空间复杂度：`O(n)`。
- 滚动变量优化后的空间复杂度：`O(1)`。

### 易错点

- `dp[i]` 表示方法数，不是最少步数。
- 初始化是 `dp[1]=1`、`dp[2]=2`，不是都初始化为 `1`。
- 遍历必须从前向后，因为当前状态依赖前面的状态。
- 题目每次只能走 `1` 或 `2` 阶，因此状态只从 `i-1` 和 `i-2` 转移。

## H_198 - 打家劫舍【Hot 100】

### 核心思路

定义 `dp[i]` 表示考虑下标 `0...i` 的房屋时，最多能够偷到的金额。对于第 `i` 间房只有两种选择：

```text
不偷当前房屋：最大金额为 dp[i-1]
偷当前房屋：不能偷 i-1，最大金额为 dp[i-2] + nums[i]
```

两种选择取最大值：

```text
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

### 面试速记

```text
dp[i] 表示考虑 0...i 房屋时能偷到的最大金额。
不偷当前是 dp[i-1]；偷当前必须跳过 i-1，是 dp[i-2]+nums[i]；
两种决策取最大值。
```

### 当前题解代码

```java
public int rob(int[] nums) {
    if (nums.length == 1) {
        return nums[0];
    }
    int[] dp = new int[nums.length];
    dp[0] = nums[0];
    dp[1] = Math.max(nums[0], nums[1]);

    for (int i = 2; i < nums.length; i++) {
        dp[i] = Math.max(dp[i - 2] + nums[i], dp[i - 1]);
    }
    return dp[nums.length - 1];
}
```

### 动态规划五步分析

#### 1. `dp` 数组含义

```text
dp[i] = 考虑下标 0...i 的所有房屋时，可以偷到的最大金额
```

`dp[i]` 不表示“一定偷第 `i` 间房”。最优方案可能偷当前，也可能跳过当前。

#### 2. 状态转移公式

```text
                     不偷 i
dp[i-1] --------------------------------┐
                                        ├──> dp[i] 取较大值
dp[i-2] + nums[i] ----------------------┘
                     偷 i，必须跳过 i-1
```

因此：

```java
dp[i] = Math.max(dp[i - 2] + nums[i], dp[i - 1]);
```

`dp[i-2]` 已经是下标 `0...i-2` 在不相邻限制下的合法最优解，它不包含房屋 `i-1`，所以可以安全地与当前房屋 `i` 组合。

#### 3. 初始化

只有一间房时：

```java
if (nums.length == 1) {
    return nums[0];
}
```

前两项初始化为：

```text
dp[0] = nums[0]
dp[1] = max(nums[0], nums[1])
```

两间房相邻，不能同时偷，所以 `dp[1]` 只能选择金额更大的那一间。

#### 4. 遍历顺序

```java
for (int i = 2; i < nums.length; i++)
```

`dp[i]` 依赖已经计算好的 `dp[i-1]` 和 `dp[i-2]`，因此从左向右遍历。

#### 5. 举例验证

以 `nums = [2,7,9,3,1]` 为例：

| `i` | `nums[i]` | 偷当前 | 不偷当前 | `dp[i]` |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 2 | 2 | - | 2 |
| 1 | 7 | 7 | 2 | 7 |
| 2 | 9 | `dp[0]+9=11` | `dp[1]=7` | 11 |
| 3 | 3 | `dp[1]+3=10` | `dp[2]=11` | 11 |
| 4 | 1 | `dp[2]+1=12` | `dp[3]=11` | 12 |

最终：

```text
nums：2  7   9   3   1
dp：  2  7  11  11  12

最优方案：偷房屋 0、2、4
总金额：2 + 9 + 1 = 12
```

### 为什么不能使用贪心

当前金额较大，不代表立即选择它一定能得到全局最大值。选择一间房会阻止相邻房屋被选择，当前决策会影响后续可选范围，因此需要保存每个前缀范围的最优结果。

### 空间优化

每次只依赖 `dp[i-1]` 和 `dp[i-2]`，可以用两个变量将空间降为 `O(1)`：

```java
public int rob(int[] nums) {
    if (nums.length == 1) {
        return nums[0];
    }

    int previousTwo = nums[0];
    int previousOne = Math.max(nums[0], nums[1]);

    for (int i = 2; i < nums.length; i++) {
        int current = Math.max(previousTwo + nums[i], previousOne);
        previousTwo = previousOne;
        previousOne = current;
    }

    return previousOne;
}
```

### 复杂度

- 当前题解时间复杂度：`O(n)`。
- 当前题解空间复杂度：`O(n)`。
- 滚动变量优化后空间复杂度：`O(1)`。

### 易错点

- `dp[i]` 是考虑到第 `i` 间房的最大金额，不表示必须偷第 `i` 间房。
- 偷当前房屋时只能接 `dp[i-2]`，不能接相邻的 `dp[i-1]`。
- `dp[1]` 应取前两间房金额的最大值，不能直接相加。
- 长度为 `1` 时需要提前返回，避免访问不存在的 `nums[1]`。

## H_62 - 不同路径【Hot 100】

### 核心思路

定义 `dp[i][j]` 表示从左上角走到坐标 `(i,j)` 的不同路径数。机器人只能向右或向下移动，所以到达当前位置的最后一步只能来自上方或左方：

```text
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

第一行只能一直向右，第一列只能一直向下，因此路径数都初始化为 `1`。

### 面试速记

```text
dp[i][j] 表示到达 (i,j) 的路径数；当前位置只能从上方或左方到达，
所以 dp[i][j] = dp[i-1][j] + dp[i][j-1]。
第一行、第一列初始化为 1，从上到下、从左到右递推。
```

### 当前题解代码

```java
public int uniquePaths(int m, int n) {
    int[][] dp = new int[m][n];
    for (int i = 0; i < m; i++) {
        dp[i][0] = 1;
    }
    for (int i = 0; i < n; i++) {
        dp[0][i] = 1;
    }

    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
        }
    }

    return dp[m - 1][n - 1];
}
```

### 动态规划五步分析

#### 1. `dp` 数组含义

```text
dp[i][j] = 从左上角走到第 i 行、第 j 列的路径数量
```

`m` 是行数，行下标为 `0...m-1`；`n` 是列数，列下标为 `0...n-1`。因此终点是 `(m-1,n-1)`。

#### 2. 状态转移公式

```text
                dp[i-1][j]
                     |
                     v
dp[i][j-1]  ->  dp[i][j]
```

来自上方的路径与来自左方的路径互不重复，所以相加：

```java
dp[i][j] = dp[i - 1][j] + dp[i][j - 1];
```

#### 3. 初始化

第一列只能一直向下走：

```java
for (int i = 0; i < m; i++) {
    dp[i][0] = 1;
}
```

第一行只能一直向右走：

```java
for (int i = 0; i < n; i++) {
    dp[0][i] = 1;
}
```

当网格只有一行或一列时，初始化已经直接得到答案 `1`，不需要额外判断。

#### 4. 遍历顺序

```java
for (int i = 1; i < m; i++) {
    for (int j = 1; j < n; j++) {
```

计算 `dp[i][j]` 时，上一行的 `dp[i-1][j]` 和当前行左侧的 `dp[i][j-1]` 必须已经计算完成。因此按照从上到下、每行从左到右的顺序遍历。

#### 5. 举例验证：`m=3, n=3`

初始化第一行和第一列：

```text
      列 0  1  2
行 0    1  1  1
   1    1  0  0
   2    1  0  0
```

依次递推：

```text
dp[1][1] = 1 + 1 = 2
dp[1][2] = 1 + 2 = 3
dp[2][1] = 2 + 1 = 3
dp[2][2] = 3 + 3 = 6
```

最终 DP 表：

```text
      列 0  1  2
行 0    1  1  1
   1    1  2  3
   2    1  3  6
```

所以从左上角到右下角共有 `6` 条路径。

### 空间优化

当前状态只依赖上方和左方，可以压缩成一维数组：

```java
public int uniquePaths(int m, int n) {
    int[] dp = new int[n];
    Arrays.fill(dp, 1);

    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            dp[j] = dp[j] + dp[j - 1];
        }
    }

    return dp[n - 1];
}
```

更新前的 `dp[j]` 表示上方的路径数，已经更新的 `dp[j-1]` 表示当前行左方的路径数：

```text
dp[j] = 上方 + 左方
```

### 复杂度

- 当前题解时间复杂度：`O(m*n)`。
- 当前题解空间复杂度：`O(m*n)`。
- 一维滚动数组空间复杂度：`O(n)`。

### 易错点

- `m` 表示行数，`n` 表示列数，终点下标是 `dp[m-1][n-1]`。
- 第一行和第一列都只有一种走法，必须初始化为 `1`。
- 状态来自上方和左方，不是右方和下方。
- 循环从下标 `1` 开始，因为第 `0` 行和第 `0` 列已经初始化。

<a id="h-64"></a>
## H_64 - 最小路径和【Hot 100】

### 核心思路

定义 `dp[i][j]` 表示从左上角走到位置 `(i,j)` 的最小路径和。当前位置只能从上方或左方到达，因此选择两个来源中路径和更小的一个，再加当前格子的值：

```text
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

第一行只能从左侧到达，第一列只能从上方到达，所以必须分别计算累加和。

### 面试速记

```text
dp[i][j] 表示到达 (i,j) 的最小路径和。
第一行从左边累加，第一列从上方累加；普通位置从上方和左方取较小值，
再加 grid[i][j]。
```

### 当前题解代码

```java
public int minPathSum(int[][] grid) {
    int[][] dp = new int[grid.length][grid[0].length];
    dp[0][0] = grid[0][0];

    for (int i = 1; i < grid.length; i++) {
        dp[i][0] = dp[i - 1][0] + grid[i][0];
    }

    for (int i = 1; i < grid[0].length; i++) {
        dp[0][i] = dp[0][i - 1] + grid[0][i];
    }

    for (int i = 1; i < grid.length; i++) {
        for (int j = 1; j < grid[0].length; j++) {
            dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
        }
    }

    return dp[grid.length - 1][grid[0].length - 1];
}
```

### 动态规划五步分析

#### 1. `dp` 数组含义

```text
dp[i][j] = 从 grid[0][0] 走到 grid[i][j] 的最小路径和
```

这个路径和包含起点和当前位置本身的数值。

#### 2. 状态转移公式

```text
                dp[i-1][j]
                     |
                     v
dp[i][j-1]  ->  dp[i][j]
```

题目求最小路径和，所以只保留两个来源中更小的路径：

```java
dp[i][j] = Math.min(dp[i - 1][j], dp[i][j - 1]) + grid[i][j];
```

#### 3. 初始化

起点没有其他来源：

```java
dp[0][0] = grid[0][0];
```

第一列只能一直向下走：

```java
dp[i][0] = dp[i - 1][0] + grid[i][0];
```

第一行只能一直向右走：

```java
dp[0][j] = dp[0][j - 1] + grid[0][j];
```

H_62 的边界表示路径数量，所以初始化为 `1`；H_64 的边界表示路径和，所以必须累加格子数值。

#### 4. 遍历顺序

计算 `dp[i][j]` 时需要上方的 `dp[i-1][j]` 和左方的 `dp[i][j-1]`，因此按照从上到下、每行从左到右遍历。

#### 5. 举例验证

```text
grid：             dp：

1  3  1            1  4  5
1  5  1            2  7  6
4  2  1            6  8  7
```

内部状态计算：

```text
dp[1][1] = min(4,2) + 5 = 7
dp[1][2] = min(5,7) + 1 = 6
dp[2][1] = min(7,6) + 2 = 8
dp[2][2] = min(6,8) + 1 = 7
```

最终最小路径和是 `7`，对应路径：

```text
1 -> 3 -> 1 -> 1 -> 1
```

### H_62 与 H_64 对比

| 对比项 | H_62 不同路径 | H_64 最小路径和 |
| --- | --- | --- |
| 目标 | 统计路径数量 | 求最小路径和 |
| 状态合并 | 上方与左方相加 | 上方与左方取最小值 |
| 第一行、第一列 | 全部初始化为 `1` | 按路径累加格子值 |
| 当前格子值 | 不参与计算 | 需要加 `grid[i][j]` |

核心公式：

```text
H_62：dp[i][j] = dp[i-1][j] + dp[i][j-1]
H_64：dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

### 为什么不能局部贪心

不能只比较当前位置右边和下边哪个格子更小。当前数字较小，不代表后续路径总和更小。动态规划比较的是到达每个位置的完整最小路径和，而不是单个相邻格子的大小。

### 空间优化

当前状态只依赖上方和左方，可以使用一维数组：

```java
public int minPathSum(int[][] grid) {
    int rows = grid.length;
    int cols = grid[0].length;

    int[] dp = new int[cols];
    dp[0] = grid[0][0];

    for (int j = 1; j < cols; j++) {
        dp[j] = dp[j - 1] + grid[0][j];
    }

    for (int i = 1; i < rows; i++) {
        dp[0] += grid[i][0];
        for (int j = 1; j < cols; j++) {
            dp[j] = Math.min(dp[j], dp[j - 1]) + grid[i][j];
        }
    }

    return dp[cols - 1];
}
```

更新前的 `dp[j]` 表示上方状态，更新后的 `dp[j-1]` 表示当前行左方状态。

### 复杂度

- 当前题解时间复杂度：`O(m*n)`。
- 当前题解空间复杂度：`O(m*n)`。
- 一维滚动数组空间复杂度：`O(n)`。

### 易错点

- 起点必须初始化为 `grid[0][0]`，不是 `0`。
- 第一行和第一列要计算路径前缀和，不能像 H_62 一样全部设为 `1`。
- 状态转移必须先取 `Math.min`，再加当前格子的数值。
- 返回位置是右下角 `dp[rows-1][cols-1]`。
