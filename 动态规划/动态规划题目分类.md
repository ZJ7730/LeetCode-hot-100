## 一、线性 DP

### 类型特征

状态沿数组或数字从左向右推进，当前状态通常依赖前面的一个或多个状态：

```text
dp[i] <- dp[i-1]、dp[i-2] 或 dp[j]（j<i）
```

### 70. 爬楼梯

基础递推 DP。

```text
dp[i]：到达第 i 阶的方法数
dp[i] = dp[i-1] + dp[i-2]
```

识别关键词：每次只能走 `1` 或 `2` 步，求方法数。

### 338. 比特位计数

数字递推 DP。

```text
dp[i]：数字 i 的二进制中 1 的数量
dp[i] = dp[i >> 1] + (i & 1)
```

`i>>1` 相当于删除最低位，`i&1` 判断最低位是否为 `1`。

### 53. 最大子数组和

连续子数组 DP。

```text
dp[i]：必须以 nums[i] 结尾的最大子数组和
dp[i] = max(nums[i], dp[i-1] + nums[i])
```

关键是“必须以当前位置结尾”，然后对所有 `dp[i]` 取最大值。

### 55. 跳跃游戏

可达性 DP，也可以使用贪心，面试更推荐贪心。

DP 定义之一：

```text
dp[i]：能否到达下标 i
如果 dp[j]=true 且 j+nums[j]>=i，则 dp[i]=true
```

贪心定义：维护当前能够覆盖的最远下标 `maxReach`。如果当前位置超过 `maxReach`，说明不可达。

### 198. 打家劫舍

相邻约束 DP。

```text
dp[i]：偷到下标 i 时能够获得的最大金额
dp[i] = max(dp[i-1], dp[i-2] + nums[i])
```

两种选择：不偷当前房屋，或偷当前房屋并跳过前一间。

### 152. 乘积最大子数组

连续子数组双状态 DP。

```text
maxDp[i]：必须以 nums[i] 结尾的最大乘积
minDp[i]：必须以 nums[i] 结尾的最小乘积
```

因为负数会让最大值和最小值交换，所以必须同时保存两者：

```text
maxDp[i] = max(nums[i], nums[i]*maxDp[i-1], nums[i]*minDp[i-1])
minDp[i] = min(nums[i], nums[i]*maxDp[i-1], nums[i]*minDp[i-1])
```

### 300. 最长递增子序列

序列 DP。

```text
dp[i]：必须以 nums[i] 结尾的最长严格递增子序列长度
```

枚举前面的结束位置：

```text
如果 nums[j] < nums[i]：
dp[i] = max(dp[i], dp[j] + 1)
```

基础动态规划时间复杂度为 `O(n^2)`，还可以使用贪心加二分优化到 `O(n log n)`。

### 线性 DP 对比

| 题目 | 状态重点 | 依赖关系 |
| --- | --- | --- |
| 70 | 到达当前位置的方法数 | 前两个位置 |
| 338 | 当前数字的比特数量 | 删除最低位后的数字 |
| 53 | 以当前位置结尾的最大和 | 前一个位置 |
| 55 | 当前是否可达 | 前面的可达位置 |
| 198 | 偷到当前位置的最大金额 | 前一个、前两个位置 |
| 152 | 以当前位置结尾的最大、最小乘积 | 前一组双状态 |
| 300 | 以当前位置结尾的 LIS 长度 | 前面所有较小元素 |

## 二、网格 DP

### 类型特征

状态位于二维网格中，当前位置通常依赖上方、左方或左上方：

```text
上方：dp[i-1][j]
左方：dp[i][j-1]
左上：dp[i-1][j-1]
```

### 62. 不同路径

网格计数 DP。

```text
dp[i][j]：从左上角到达位置 (i,j) 的路径数量
dp[i][j] = dp[i-1][j] + dp[i][j-1]
```

第一行和第一列都只有一种走法，初始化为 `1`。

### 64. 最小路径和

网格最小值 DP。

```text
dp[i][j]：从左上角到达位置 (i,j) 的最小路径和
dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]
```

第一行和第一列只能沿唯一方向走，因此要计算路径前缀和。

### 221. 最大正方形

网格形状 DP。

```text
dp[i][j]：以 matrix[i][j] 为右下角的最大正方形边长
```

当当前格子是 `'1'`：

```text
dp[i][j] = min(
    dp[i-1][j],
    dp[i][j-1],
    dp[i-1][j-1]
) + 1
```

答案要求面积，所以最后返回 `最大边长 * 最大边长`。

### 网格 DP 对比

```text
62：上方和左方相加，求路径数量
64：上方和左方取最小，求路径代价
221：上、左、左上取最小，求正方形边长
```

## 三、字符串 DP

### 72. 编辑距离

双字符串 DP。

```text
dp[i][j]：word1 前 i 个字符转换成 word2 前 j 个字符的最少操作数
```

如果最后一个字符相同：

```text
dp[i][j] = dp[i-1][j-1]
```

如果不同，从删除、插入、替换中选择代价最小的操作：

```text
dp[i][j] = min(
    dp[i-1][j],
    dp[i][j-1],
    dp[i-1][j-1]
) + 1
```

### 139. 单词拆分

字符串前缀 DP，也可以理解成完全背包可行性问题。

```text
dp[i]：字符串前 i 个字符能否被字典中的单词拆分
dp[0] = true
```

枚举切分点 `j`：

```text
如果 dp[j]=true，并且 s[j..i) 在字典中：
dp[i] = true
```

单词可以重复使用，因此从背包角度属于完全背包；字符串的字符顺序不能改变，因此按前缀位置推进更容易理解。

### 字符串 DP 对比

```text
72：两个字符串前缀之间的最少操作数，二维状态
139：一个字符串前缀是否可拆分，一维可行性状态
```

## 四、回文区间 DP

### 5. 最长回文子串

区间布尔 DP。

```text
dp[i][j]：字符串区间 s[i..j] 是否为回文串
```

状态转移：

```text
s[i] == s[j]，并且：
1. j-i<=1，区间长度为 1 或 2；或者
2. dp[i+1][j-1] == true

则 dp[i][j] = true
```

因为外层区间依赖内部区间 `dp[i+1][j-1]`，所以左端点 `i` 要从后向前遍历，右端点 `j` 从 `i` 向后遍历。

```text
大区间 [i........j]
          依赖
小区间   [i+1..j-1]
```

这道题也可以使用中心扩展法，空间复杂度更低；从动态规划分类看，它属于回文区间 DP。

## 五、背包 DP

### 类型总览

| 题目 | 模型 | 目标 | 容量顺序 |
| --- | --- | --- | --- |
| 416. 分割等和子集 | 0-1 背包 | 是否能恰好装满 | 倒序 |
| 494. 目标和 | 0-1 背包 | 恰好装满的方案数 | 倒序 |
| 279. 完全平方数 | 完全背包 | 最少物品数量 | 正序 |
| 322. 零钱兑换 | 完全背包 | 最少物品数量 | 正序 |

### 416. 分割等和子集

把问题转换为：能否从数组中选择一些元素，使它们的和等于总和的一半。

每个数组元素只能使用一次，因此是 0-1 背包。

```text
target = sum / 2
dp[j]：能否从已处理元素中凑出和 j
dp[0] = true
dp[j] = dp[j] || dp[j-nums[i]]
```

容量必须倒序，避免同一个元素被重复使用。

### 494. 目标和

设添加正号的元素和为 `positive`，添加负号的元素和为 `negative`：

```text
positive - negative = target
positive + negative = sum
```

相加得到：

```text
positive = (sum + target) / 2
```

问题转换成：从数组中选择若干元素，使其和等于 `positive`，求方案数量。

```text
dp[j]：从已处理元素中凑出 j 的方案数
dp[0] = 1
dp[j] += dp[j-nums[i]]
```

每个元素只能使用一次，容量倒序。

### 279. 完全平方数

完全平方数 `1、4、9……` 是可以无限使用的物品，`n` 是背包容量。

```text
dp[j]：凑出 j 所需的最少完全平方数数量
dp[0] = 0，其他位置初始化为无穷大
dp[j] = min(dp[j], dp[j-square] + 1)
```

平方数可以重复使用，容量正序。

### 322. 零钱兑换

硬币是可以无限使用的物品，金额是背包容量。

```text
dp[j]：凑出金额 j 所需的最少硬币数量
dp[0] = 0，其他位置初始化为无穷大
dp[j] = min(dp[j], dp[j-coin] + 1)
```

它与 279 的模型完全相同，区别只是物品来源不同：

```text
279：物品是自动生成的平方数
322：物品是题目给出的硬币
```

背包的完整理论和模板参见：[背包理论复盘](./背包理论复盘.md)。

## 六、股票状态机 DP

### 类型特征

每天结束时可能处于不同持仓状态。状态转移不仅取决于天数，还取决于当前是否持股、是否处于冷冻期。

### 121. 买卖股票的最佳时机

只能完成一次买入和一次卖出。

状态机写法：

```text
hold[i]：第 i 天结束时持有股票的最大利润
cash[i]：第 i 天结束时不持有股票的最大利润

hold[i] = max(hold[i-1], -prices[i])
cash[i] = max(cash[i-1], hold[i-1] + prices[i])
```

因为只能买入一次，买入状态是 `-prices[i]`，不能使用此前卖出的利润再次买入。

这道题也可以维护历史最低价格，使用贪心求解。

### 309. 买卖股票的最佳时机含冷冻期

卖出股票后的第二天不能买入，因此需要区分更多状态。

可以定义：

```text
hold：当天结束持有股票
sold：当天刚卖出股票
rest：当天不持股，并且不处于刚卖出的状态
```

转移关系：

```text
newHold = max(hold, rest - price)
newSold = hold + price
newRest = max(rest, sold)
```

核心限制体现在：买入只能从 `rest` 转移，不能从当天刚卖出的 `sold` 直接转移。

### 股票题速记

```text
先定义每天结束时有哪些状态，再画出状态之间允许的转移。
121：持股、不持股
309：持股、刚卖出、休息
```

## 七、计数与构造 DP

### 96. 不同的二叉搜索树

卡特兰数型计数 DP。

```text
dp[i]：由 i 个不同节点组成的二叉搜索树数量
dp[0] = 1
```

枚举根节点 `root`：

```text
左子树节点数  = root-1
右子树节点数  = i-root
```

左右结构独立组合，因此相乘；不同根节点的结果互斥，因此相加：

```text
dp[i] += dp[root-1] * dp[i-root]
```

### 22. 括号生成

主要解法是回溯，不建议为了套动态规划而强行使用 DP。

动态规划构造思路与 96 的卡特兰结构相同：一个合法括号序列可以拆成：

```text
"(" + left + ")" + right
```

其中 `left` 使用 `k` 对括号，`right` 使用 `n-1-k` 对括号：

```text
dp[n] = 所有 "(" + dp[k] + ")" + dp[n-1-k] 的集合
```

但因为需要实际生成所有字符串，回溯的“左括号数量不超过 n，右括号数量不超过左括号”更直接。

### 两题联系

```text
96：只统计卡特兰结构的数量
22：生成每一种卡特兰结构对应的括号字符串
```

## 八、树形 DP

### 337. 打家劫舍 III

树形后序 DP。

每个节点返回两个状态：

```text
notRob：不偷当前节点时，当前子树的最大金额
rob：偷当前节点时，当前子树的最大金额
```

如果偷当前节点，就不能偷它的孩子：

```text
rob = node.val + left.notRob + right.notRob
```

如果不偷当前节点，每个孩子都可以选择偷或不偷：

```text
notRob = max(left.notRob, left.rob)
       + max(right.notRob, right.rob)
```

必须先得到左右子树的状态才能计算当前节点，所以使用后序遍历：

```text
左子树 -> 右子树 -> 当前节点
```

它和 198 的关系：

```text
198：线性结构中，相邻节点不能同时选择
337：树形结构中，父节点和孩子不能同时选择
```

```

目标：先掌握 0-1 背包倒序，再掌握完全背包正序。

```

## 十一、面试速记

### 一句话分类

```text
线性 DP：当前位置依赖前面位置。
网格 DP：当前格依赖上、左或左上。
字符串 DP：状态表示一个或两个字符串前缀。
区间 DP：状态表示区间 [i,j]，通常由小区间推大区间。
背包 DP：从物品中选择，选择总和受容量限制。
状态机 DP：同一位置存在持有、未持有等多个状态。
树形 DP：子树先计算，再合并到父节点。
```

### 易混淆题目

```text
53 与 152：
53 只维护最大和；152 因为负数，需要同时维护最大、最小乘积。

62 与 64：
62 将来源路径数相加；64 对来源代价取最小后加当前值。

279 与 322：
都是完全背包最小数量，只是物品分别为平方数和硬币。

198 与 337：
都是相邻节点不能同时选择，区别是线性结构和树形结构。

121 与 309：
都是股票状态机，309 多了卖出后的冷冻限制。

22 与 96：
都具有卡特兰结构；22 生成具体结果，96 只统计数量。
```
