## 一、背包问题是什么

标准背包问题包含以下元素：

```text
物品：可以选择的元素
重量：选择该元素会消耗多少容量
价值：选择该元素能获得多少收益
背包容量：能够使用的总容量
目标：求最大价值、是否可行、方案数量或最少物品数
```

标准最大价值问题：

```text
有 n 件物品，物品 i 的重量为 weight[i]，价值为 value[i]。
背包容量为 W，求不超过容量 W 时可以获得的最大价值。
```

背包不一定是真正的书包。在力扣题目中：

```text
数组元素、硬币、单词、平方数  -> 物品
目标和、金额、整数 n          -> 背包容量
元素的数值                    -> 物品重量
```

## 二、如何识别背包问题

看到下面的题目特征时，可以考虑背包模型：

```text
1. 从一组元素中选择若干个。
2. 每个元素有重量、数值或消耗。
3. 所选元素的总和受到目标值限制。
4. 求最大值、最小值、能否组成或组成方案数。
```

第一步先判断每个物品能使用几次：

| 物品限制 | 背包模型 |
| --- | --- |
| 每个物品最多使用一次 | 0-1 背包 |
| 每个物品可以无限次使用 | 完全背包 |
| 每个物品最多使用指定次数 | 多重背包 |

第二步判断题目求什么：

```text
最大价值：使用 max
最少数量：使用 min
是否可行：使用 boolean
方案数量：使用加法累加
```

## 三、0-1 背包二维 DP

### 1. 模型

0-1 背包中，每件物品只有两个选择：

```text
0：不选择
1：选择一次
```

不能重复选择同一件物品。

使用下面的例子：

| 物品 | 重量 | 价值 |
| --- | ---: | ---: |
| 0 | 1 | 15 |
| 1 | 3 | 20 |
| 2 | 4 | 30 |

背包容量为 `4`。

### 2. 状态定义

```text
dp[i][j]：从下标 0 到 i 的物品中任意选择，
          放入容量为 j 的背包，可以获得的最大价值
```

两个维度分别表示：

```text
i：已经考虑到哪一件物品
j：当前背包容量
```

### 3. 状态转移

计算 `dp[i][j]` 时，对物品 `i` 有两种选择。

不选择物品 `i`：

```text
dp[i-1][j]
```

选择物品 `i`：

```text
dp[i-1][j-weight[i]] + value[i]
```

为什么选择后仍然使用上一行 `i-1`？

```text
物品 i 已经选择了一次，剩余容量不能再次选择物品 i，
所以只能从前 i-1 件物品的结果继续推导。
```

转移公式：

```text
dp[i][j] = max(
    dp[i-1][j],
    dp[i-1][j-weight[i]] + value[i]
)
```

状态来源图：

```text
dp[i-1][j] ───────────────────────┐  不选物品 i
                                  ▼
                              dp[i][j]
                                  ▲
dp[i-1][j-weight[i]] + value[i] ──┘  选择物品 i
```

如果 `j<weight[i]`，当前背包装不下物品 `i`：

```text
dp[i][j] = dp[i-1][j]
```

### 4. 初始化

容量为 `0` 时，最大价值为 `0`：

```text
dp[i][0] = 0
```

第一行只允许选择物品 `0`：

```text
j < weight[0]  ：dp[0][j] = 0
j >= weight[0] ：dp[0][j] = value[0]
```

注意 0-1 背包中的物品 `0` 只能放一次，容量再大也不能重复增加它的价值。

### 5. DP 表推导

```text
容量 j       0   1   2   3   4
只看物品0    0  15  15  15  15
看到物品1    0  15  15  20  35
看到物品2    0  15  15  20  35
```

例如：

```text
dp[1][4]
= max(dp[0][4], dp[0][4-3] + 20)
= max(15, 15+20)
= 35
```

对应选择重量为 `1` 和 `3` 的两个物品。

### 6. Java 模板

```java
public int zeroOneKnapsack2D(int[] weight, int[] value, int capacity) {
    int itemCount = weight.length;
    int[][] dp = new int[itemCount][capacity + 1];

    for (int j = weight[0]; j <= capacity; j++) {
        dp[0][j] = value[0];
    }

    for (int i = 1; i < itemCount; i++) {
        for (int j = 0; j <= capacity; j++) {
            if (j < weight[i]) {
                dp[i][j] = dp[i - 1][j];
            } else {
                dp[i][j] = Math.max(
                    dp[i - 1][j],
                    dp[i - 1][j - weight[i]] + value[i]
                );
            }
        }
    }

    return dp[itemCount - 1][capacity];
}
```

时间复杂度为 `O(n*W)`，空间复杂度为 `O(n*W)`。

## 四、0-1 背包一维 DP

### 1. 为什么能压缩成一维

二维公式：

```text
dp[i][j] = max(dp[i-1][j], dp[i-1][j-weight[i]] + value[i])
```

第 `i` 行只依赖第 `i-1` 行，因此可以让一维数组复用上一行的数据：

```text
更新前的 dp[j]             -> dp[i-1][j]
更新前的 dp[j-weight[i]]   -> dp[i-1][j-weight[i]]
```

压缩后：

```text
dp[j]：容量为 j 的背包可以获得的最大价值
```

转移公式：

```java
dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
```

### 2. 为什么必须倒序遍历容量

0-1 背包要求每件物品只能使用一次。

假设只有一个物品，重量为 `1`、价值为 `15`。如果正序遍历：

```text
dp[1] = dp[0] + 15 = 15
dp[2] = dp[1] + 15 = 30
                 ↑
           使用了本轮刚更新的 dp[1]
```

结果相当于同一个物品被放入两次，违反 0-1 背包限制。

倒序遍历时：

```text
先算 dp[2]，此时 dp[1] 还是上一轮的状态
再算 dp[1]
```

所以本轮每个物品最多只会使用一次。

```text
0-1 背包一维数组：容量必须从大到小遍历
```

### 3. Java 模板

```java
public int zeroOneKnapsack1D(int[] weight, int[] value, int capacity) {
    int[] dp = new int[capacity + 1];

    for (int i = 0; i < weight.length; i++) {
        for (int j = capacity; j >= weight[i]; j--) {
            dp[j] = Math.max(
                dp[j],
                dp[j - weight[i]] + value[i]
            );
        }
    }

    return dp[capacity];
}
```

时间复杂度为 `O(n*W)`，空间复杂度降低为 `O(W)`。

### 4. 循环顺序

一维 0-1 背包必须：

```text
外层遍历物品
内层倒序遍历容量
```

不能交换两层循环。交换后不能正确表达“逐件开放物品，并保证每件最多使用一次”。

## 五、完全背包二维 DP

### 1. 模型

完全背包与 0-1 背包唯一的本质区别：

```text
0-1 背包：每件物品最多使用一次
完全背包：每种物品可以使用无限次
```

### 2. 状态定义

```text
dp[i][j]：使用下标 0 到 i 的物品，每种物品可以使用无限次，
          容量为 j 时能够获得的最大价值
```

### 3. 状态转移

不选择物品 `i`：

```text
dp[i-1][j]
```

选择一个物品 `i`：

```text
dp[i][j-weight[i]] + value[i]
```

为什么是当前行 `dp[i][...]`？

```text
选择一个物品 i 后，剩余容量仍然允许继续选择物品 i，
所以子问题仍然可以使用前 i 种物品。
```

转移公式：

```text
dp[i][j] = max(
    dp[i-1][j],
    dp[i][j-weight[i]] + value[i]
)
```

状态来源图：

```text
dp[i-1][j] ─────────────────────┐  不选物品 i
                                ▼
                            dp[i][j]
                                ▲
dp[i][j-weight[i]] + value[i] ──┘  再选一个物品 i
```

### 4. 和 0-1 背包的关键区别

```text
0-1 背包选择物品 i：
dp[i-1][j-weight[i]] + value[i]
   ↑ 上一行，不能再选物品 i

完全背包选择物品 i：
dp[i][j-weight[i]] + value[i]
   ↑ 当前行，还可以继续选物品 i
```

### 5. Java 模板

```java
public int completeKnapsack2D(int[] weight, int[] value, int capacity) {
    int itemCount = weight.length;
    int[][] dp = new int[itemCount][capacity + 1];

    for (int j = weight[0]; j <= capacity; j++) {
        dp[0][j] = dp[0][j - weight[0]] + value[0];
    }

    for (int i = 1; i < itemCount; i++) {
        for (int j = 0; j <= capacity; j++) {
            if (j < weight[i]) {
                dp[i][j] = dp[i - 1][j];
            } else {
                dp[i][j] = Math.max(
                    dp[i - 1][j],
                    dp[i][j - weight[i]] + value[i]
                );
            }
        }
    }

    return dp[itemCount - 1][capacity];
}
```

## 六、完全背包一维 DP

### 1. 状态与转移

```text
dp[j]：容量为 j 时可以获得的最大价值
```

```java
dp[j] = Math.max(dp[j], dp[j - weight[i]] + value[i]);
```

公式和一维 0-1 背包相同，区别在容量遍历方向。

### 2. 为什么必须正序遍历容量

完全背包允许重复使用当前物品，因此需要使用本轮刚更新的状态。

假设当前物品重量为 `1`、价值为 `15`：

```text
dp[1] = dp[0] + 15 = 15
dp[2] = dp[1] + 15 = 30
dp[3] = dp[2] + 15 = 45
```

依赖关系：

```text
dp[0] --放一个--> dp[1] --再放一个--> dp[2] --再放一个--> dp[3]
```

正序遍历正好允许当前物品被重复使用。

```text
完全背包一维数组：容量从小到大遍历
```

### 3. Java 模板

```java
public int completeKnapsack1D(int[] weight, int[] value, int capacity) {
    int[] dp = new int[capacity + 1];

    for (int i = 0; i < weight.length; i++) {
        for (int j = weight[i]; j <= capacity; j++) {
            dp[j] = Math.max(
                dp[j],
                dp[j - weight[i]] + value[i]
            );
        }
    }

    return dp[capacity];
}
```

时间复杂度为 `O(n*W)`，空间复杂度为 `O(W)`。

## 七、0-1 背包与完全背包对比

| 对比项 | 0-1 背包 | 完全背包 |
| --- | --- | --- |
| 每种物品使用次数 | 最多一次 | 无限次 |
| 二维 DP 不选当前物品 | `dp[i-1][j]` | `dp[i-1][j]` |
| 二维 DP 选择当前物品 | `dp[i-1][j-weight]+value` | `dp[i][j-weight]+value` |
| 一维 DP 公式 | `dp[j]=max(dp[j], dp[j-weight]+value)` | 相同 |
| 一维容量顺序 | 从大到小 | 从小到大 |
| 顺序的目的 | 避免重复使用当前物品 | 允许重复使用当前物品 |

最重要的记忆图：

```text
0-1背包：
上一行 dp[i-1][j-weight] --选一次--> 当前行 dp[i][j]

完全背包：
当前行 dp[i][j-weight]   --再选一次--> 当前行 dp[i][j]
```

一维模板只差一个遍历方向：

```java
// 0-1 背包
for (物品 i) {
    for (int j = capacity; j >= weight[i]; j--) {
        更新 dp[j];
    }
}

// 完全背包
for (物品 i) {
    for (int j = weight[i]; j <= capacity; j++) {
        更新 dp[j];
    }
}
```

## 八、不同问题类型的初始化

背包题不能只背递推公式。初始化必须与 `dp` 的定义和目标一致。

### 1. 求不超过容量的最大价值

```text
dp[j] = 0
```

容量不要求恰好装满，什么都不选就是价值 `0`。

转移：

```java
dp[j] = Math.max(dp[j], dp[j - weight] + value);
```

### 2. 求能否恰好凑出目标值

```text
dp[0] = true
其他位置 = false
```

`dp[0]=true` 表示不选择任何物品可以组成和 `0`。

转移：

```java
dp[j] = dp[j] || dp[j - weight];
```

### 3. 求恰好凑出的方案数量

```text
dp[0] = 1
其他位置 = 0
```

`dp[0]=1` 表示凑出 `0` 有一种方案：什么都不选。它是所有方案计数的递推起点。

转移：

```java
dp[j] += dp[j - weight];
```

### 4. 求恰好凑出的最少物品数量

```text
dp[0] = 0
其他位置 = infinity
```

转移：

```java
dp[j] = Math.min(dp[j], dp[j - weight] + 1);
```

如果不保证目标一定可达，更新前需要判断：

```java
if (dp[j - weight] != infinity) {
    dp[j] = Math.min(dp[j], dp[j - weight] + 1);
}
```

### 5. 初始化对比表

| 问题目标 | `dp[0]` | 其他位置 | 状态合并 |
| --- | ---: | --- | --- |
| 最大价值，不要求装满 | `0` | `0` | `max` |
| 是否恰好装满 | `true` | `false` | 逻辑或 |
| 恰好装满的方案数 | `1` | `0` | 加法 |
| 恰好装满的最少数量 | `0` | `infinity` | `min` |

## 九、组合数与排列数

当完全背包题目要求统计方案数量时，两层循环的顺序会决定是否区分元素顺序。

### 1. 求组合数：物品在外层

```java
dp[0] = 1;

for (int item : items) {
    for (int j = item; j <= target; j++) {
        dp[j] += dp[j - item];
    }
}
```

物品按固定顺序逐个开放，`1+2` 和 `2+1` 只统计一次。

典型题：`518. 零钱兑换 II`。

### 2. 求排列数：背包在外层

```java
dp[0] = 1;

for (int j = 1; j <= target; j++) {
    for (int item : items) {
        if (j >= item) {
            dp[j] += dp[j - item];
        }
    }
}
```

计算每个目标时枚举最后一个物品，`1+2` 和 `2+1` 会分别统计。

典型题：`377. 组合总和 IV`。

### 3. 最大值和最小值问题

最大值、最小值问题不统计不同顺序的方案。在状态依赖合法的前提下，物品和容量谁在外层通常不影响最终最优值。

为了保持模板统一，优先使用：

```text
外层遍历物品，内层按照背包类型遍历容量。
```

## 十一、统一解题步骤

### 动态规划五步法

```text
1. 定义 dp 数组以及下标含义。
2. 推导状态转移公式。
3. 根据状态定义确定初始化。
4. 根据物品使用次数和题目目标确定遍历顺序。
5. 用一个小例子手工推导 dp 数组。
```

### 背包题判断流程

```text
从若干元素中选择，且总和受到目标限制？
                │
                ▼
           考虑背包模型
                │
       ┌────────┴────────┐
       ▼                 ▼
每个元素最多一次      每个元素无限次
   0-1背包             完全背包
       │                 │
       ▼                 ▼
一维容量倒序          一维容量正序
                │
                ▼
判断求 max、min、boolean 还是方案数
                │
                ▼
根据目标决定初始化和状态合并方式
```

### 调试方法

如果代码结果不正确，按顺序检查：

```text
1. dp[j] 的含义是否写清楚。
2. 是否要求恰好装满。
3. dp[0] 和其他状态是否初始化正确。
4. 物品能否重复使用。
5. 容量应该正序还是倒序。
6. 求方案数时是否区分组合与排列。
7. 手工打印小规模 dp 数组，与推导表对比。
```

## 十二、面试速记

### 一句话区分

```text
0-1背包：每件物品只能选一次，一维容量倒序。
完全背包：每件物品可以无限选，一维容量正序。
```

### 二维公式

```text
0-1背包：
dp[i][j] = max(dp[i-1][j], dp[i-1][j-weight[i]] + value[i])

完全背包：
dp[i][j] = max(dp[i-1][j], dp[i][j-weight[i]] + value[i])
                                    ↑ 当前行，可以重复选择
```

### 一维公式

```text
两者公式相同：
dp[j] = max(dp[j], dp[j-weight[i]] + value[i])

区别只在容量顺序：
0-1背包倒序，完全背包正序。
```

### 四种目标

```text
求最大值：max
求最小值：min，dp[0]=0，其他为无穷大
求可行性：boolean，dp[0]=true
求方案数：累加，dp[0]=1
```

### 最终记忆
